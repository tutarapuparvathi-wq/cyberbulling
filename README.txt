CYBERSAFE - CYBERBULLYING DETECTION AWARENESS WEBSITE

Files:
- index.html
- style.css
- script.js

How to run:
1. Extract the ZIP.
2. Open index.html in a browser.
3. Use the Message Analyzer and Safety Report sections.

Important:
This is an educational/demo project. The detector is rule-based and does not provide a definitive determination of cyberbullying. It does not send reports to authorities or platforms and does not store submitted messages on a server.
